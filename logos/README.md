# Logos — Usage Guide

Never redraw, recreate, recolor, or distort a logo. Always place these files as-is, scaled proportionally only.

## Available files and when to use them

### Performance Property (master brand)
| File | Use on |
|---|---|
| `performance-property/pp-logo-standard.png` | White / light backgrounds |
| `performance-property/pp-logo-inverted.png` | Dark backgrounds (e.g. Dark Teal `#171B24`) |
| `performance-property/pp-logo-white.png` | Photos and strong color backgrounds (all-white mono) |
| `performance-property/pp-logo-black.png` | Grayscale / single-color print |

### Property for Doctors
| File | Use on |
|---|---|
| `property-for-doctors/pfd-logo-black.png` | White / light backgrounds; grayscale print |
| `property-for-doctors/pfd-logo-white.png` | Dark or colored backgrounds |

Only these two variants exist for this sub-brand.

### Performance Asset Management
| File | Use on |
|---|---|
| `asset-management/pam-logo-standard.png` | White / light backgrounds |
| `asset-management/pam-logo-inverted.png` | Dark backgrounds |
| `asset-management/pam-logo-standard-inverted.png` | Alternate inverted lockup |
| `asset-management/pam-logo-white.png` | Eucalyptus green `#3E7967` background — the brand book's green-background treatment is ONLY permitted on this green, never elsewhere. Also usable on photos/dark surfaces. |
| `asset-management/pam-logo-black.png` | Grayscale / single-color print |

## Hard rules (from the brand book)

- Safe area: clear space equal to the symbol's height/width on all sides.
- Minimum height: 6 mm (print), 35 px (digital).
- Never: remove/alter the tagline, drop shadows, outlines, stretching, rotation, recoloring, or rearranging elements.
- Sub-brands follow all master-brand rules.

## Formats

PNGs are high-resolution masters with transparent backgrounds. If a vector version is required (large-format print, signage), export SVG/EPS from the Illustrator source — do not vectorize the PNGs.
